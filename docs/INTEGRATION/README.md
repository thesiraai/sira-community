# Integration Documentation

This directory contains all integration-related documentation for SIRA Community.

## 📚 Documentation Files

- **`INTEGRATION_GUIDE.md`** - Comprehensive integration guide for SIRA AI app and other services
- **`ONE_PRODUCT_EXECUTION_QUESTIONS.md`** - Pre-execution questions/checklist for “one product” Community under `https://app.sira.ai/community`
- **`ONE_PRODUCT_EXECUTION_PLAN.md`** - Community-team execution plan for running Discourse under `/community`

## 🔗 Integration Points

### SIRA AI App Integration
- REST API integration
- Single Sign-On (SSO)
- Webhooks
- OAuth 2.0
- Embedding options

### Infrastructure Integration
- PostgreSQL (with mTLS)
- Redis (with TLS)
- Network connectivity via `sira_infra_network`
