# Discourse SIRA AI Plugin

This plugin integrates SIRA AI features into Discourse.

## Features

- SIRA AI API integration
- Custom SIRA AI functionality
- (Additional features to be added)

## Installation

This plugin is automatically loaded when mounted in the Discourse Docker container.

## Configuration

Configure the following settings in Discourse admin panel:

- `sira_ai_enabled`: Enable/disable SIRA AI features
- `sira_api_url`: SIRA AI API URL
- `sira_api_key`: SIRA AI API key

## Development

This plugin follows standard Discourse plugin structure.
